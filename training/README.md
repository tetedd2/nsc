# 🏋️ Phase 3 — เทรน "น้องซี" ด้วย LoRA (ฟรีบน Google Colab)

fine-tune โมเดลภาษาไทยตัวเล็กให้เป็นผู้ช่วยการเงิน "น้องซี" ที่ **ตอบเฉพาะเรื่องการเงิน**
โดยใช้ dataset จากโฟลเดอร์ [`../data/`](../data/)

## 📁 ไฟล์

| ไฟล์ | คืออะไร |
|------|---------|
| `finetune_nong_see_colab.ipynb` | โน้ตบุ๊ก Colab พร้อมรัน (ติดตั้ง → เทรน → ทดสอบ → ส่งออก) |

## 🚀 ขั้นตอนใช้งาน

### 1. สร้าง dataset ก่อน (บนเครื่อง)
```bash
node data/build-dataset.cjs
```
จะได้ `data/finance_th.train.jsonl` และ `data/finance_th.val.jsonl`

### 2. เปิดโน้ตบุ๊กบน Colab
- ไปที่ https://colab.research.google.com → `File` → `Upload notebook` → เลือก `finetune_nong_see_colab.ipynb`
- เปิด GPU ฟรี: `Runtime` → `Change runtime type` → **T4 GPU** → `Save`

### 3. รันทีละเซลล์
- เซลล์อัปโหลด dataset จะให้เลือกไฟล์ → อัปโหลด **`finance_th.train.jsonl` + `finance_th.val.jsonl`**
- รอเทรน (~10–30 นาทีบน T4)

### 4. ตรวจผล
- เซลล์ทดสอบคำถามการเงิน → ดูว่าตอบเป็นน้องซีไหม
- **เซลล์ทดสอบ guardrail** → ถามนอกเรื่อง (เขียนโค้ด/เลขเด็ด/หุ้นตัวไหนขึ้น) โมเดลต้อง **ปฏิเสธสุภาพ** แล้วชวนกลับเรื่องการเงิน

### 5. บันทึก/ส่งออก
- **(ก)** LoRA adapter (เล็ก) → ดาวน์โหลด `nong_see_lora.zip`
- **(ข)** รวมเป็นโมเดลเต็ม 16-bit (เสิร์ฟด้วย vLLM/transformers)
- **(ค)** GGUF quantize (รันด้วย llama.cpp / Ollama / ในเบราว์เซอร์)

## ⚙️ ปรับแต่งได้

| ตัวแปร (ในโน้ตบุ๊ก) | ค่าเริ่มต้น | หมายเหตุ |
|----|----|----|
| `MODEL_NAME` | `unsloth/Qwen2.5-3B-Instruct-bnb-4bit` | เปลี่ยนเป็น `1.5B` ถ้าอยากเร็ว, `7B` ถ้าอยากเก่งขึ้น |
| `CHAT_TEMPLATE` | `qwen-2.5` | **ต้องตรงกับโมเดล** ถ้าเปลี่ยนโมเดลตระกูลอื่นต้องปรับ |
| `num_train_epochs` | 3 | ลอง 2–4; ข้อมูลน้อยอย่าเทรนเกินจนจำ (overfit) |
| `learning_rate` | 2e-4 | ค่ามาตรฐานสำหรับ LoRA |

### โมเดลไทยทางเลือก
- **Qwen2.5** (ค่าเริ่มต้น) — ไทยใช้ได้ดี มี Unsloth 4-bit พร้อม
- **Typhoon (SCB10X)** — ไทยเฉพาะทาง (ต้องปรับ chat template ให้ตรง)
- **SeaLLM** — เน้นภาษาเอเชียตะวันออกเฉียงใต้

## 💡 เคล็ดลับคุณภาพ
- ถ้าโมเดล **ตอบนอกเรื่องการเงิน** → เพิ่มตัวอย่าง `category: "guardrail"` ใน `data/finance-qa-source.json` แล้ว build + เทรนใหม่
- ถ้า **ตอบน้ำท่วมทุ่ง/วกวน** → ลด epoch หรือเพิ่มข้อมูลที่หลากหลาย
- เก็บ val set ไว้เทียบเสมอ อย่าดูแค่ train loss
